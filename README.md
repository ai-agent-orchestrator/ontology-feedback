# Ontology Feedback

이 저장소는 학습 과정에서 발생한 현실 환경 문제, 피드백, 원인 분석, 보정 과정을 기록하기 위한 개인 학습 로그 저장소입니다.

## 목적

개발 학습은 코드만으로 이루어지지 않습니다.

실제 학습 환경, 도구 설정, 사용자 경험, 오류 원인, 피드백 과정이 함께 맞물려야 정상적으로 진행됩니다.

이 저장소는 다음 내용을 정리하기 위해 분리했습니다.

- 학습 환경 문제 기록
- Java 개발 환경 설정 오류 분석
- 실제 실행 오류와 원인 추적
- AI 도구를 활용한 문제 진단 과정
- 현실 피드백을 바탕으로 한 학습 환경 보정

## 핵심 관점

```text
현실 문제 발견
-> 원인 기록
-> 기술적 진단
-> 피드백 정리
-> 환경 보정
-> 학습 흐름 회복
```

## 개인 메모

이 저장소는 포트폴리오용 완성 프로젝트라기보다, 학습 과정에서 현실 조건이 코드 학습에 어떤 영향을 주는지 기록하기 위한 저장소입니다.

공개 여부는 문서의 민감도에 따라 신중하게 결정하는 것을 권장합니다.
